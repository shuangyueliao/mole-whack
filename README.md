# Mole Whack

Free single-file HTML5 whack-a-mole game. Bop goofy moles popping from a 3x3
meadow for 30 seconds — chain hits to build combo multipliers, grab golden
moles for triple points, and keep the mallet away from the bombs. Earn a rank
from F to S. One HTML file, zero assets.

**Play:** https://shuangyueliao.github.io/mole-whack/

- Mouse / touch, procedural WebAudio sounds (hit / gold / bomb / whiff)
- Procedural meadow visuals: sun, clouds, grass tufts, flowers, glowing moles
- Combo scoring (up to x2), shrinking mole timings, F–S rating, best score
  and rank saved locally
- Procedural graphics, no dependencies, no tracking
